How this follows Apple's Human Interface Guidelines
One number firstThe delay is the answer, so it is the largest thing on the card. Everything else supports it.
Plain language“Lights wait 2.24 s so they match Study”, not “residual” or “probe”. Technical terms live behind Details.
Progressive disclosureThe breakdown (measured, Player Delay, trim) is one tap away, closed by default.
Direct manipulationFine-tune sits beside the number, in the user's words: earlier and later. Changes save at once and say so.
Status you can read without colourEach state has an icon, a word and a colour, so it works for colour-blind users and screen readers.
Collapse without losing the answerThe arrow folds the card to one line that still shows the state and the delay. It rotates like a Finder disclosure triangle, and the choice is remembered.
Honest confidenceThe sparkline and “±” show how steady the measurement is, instead of implying false precision.
