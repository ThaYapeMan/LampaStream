## Music colour upgrade

`palettes-mockup.html`, `music-settings-mockup.html`,
`effect-palette-mockup.html` and `now-playing-music-mockup.html` provide desktop
and responsive phone references for the palette editor, genre/rule/transition
settings, effect palette picker and Now Playing additions. These were created
before the product screens; implementation uses existing components and tokens.
See [Music colours and transitions](../music-colours.md) for design decisions.

`lights-row-and-appearance.png` is the owner's approved design for the permanent
Now Playing Lights row and the sidebar Appearance control. State annotations
in that image describe alternatives; they are not interface elements.
